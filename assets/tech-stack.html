2引擎层 preload.js（Node 桥接）

全部系统能力集中暴露为 window.pilot，渲染层零 Node 依赖

Git 引擎status --porcelain=v2 解析未提交/暂存/未跟踪，log diff add/commit/push/pull，无远端仓库降级可用
进程引擎cmd /c 一次性任务 + 常驻服务进程句柄，taskkill /T /F 进程树强杀，输出环形缓冲
文件引擎目录浏览（忽略 node_modules 等）、文本预览/编辑（512KB 上限 + 二进制嗅探）、重命名/删除
存储utools.db 版本化读写（_rev 冲突处理），项目/设置分离存储
AI 客户端OpenAI 兼容 /chat/completions，https/http 双栈，120s 超时，错误体透传
系统集成打开文件夹/终端（wt.exe 优先）、系统通知、复制文本

数据流

  • uTools 唤起 → Store 加载 db
  • 仪表盘 → 并发 git status → 卡片徽章
  • 操作 → preload 执行 → 视图重渲染
  • 变更 → dbPut 持久化
